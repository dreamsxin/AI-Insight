STEP 1两种答法

直接交卷，还是先列草稿

普通模型把全部本事用在「第一反应」；推理模型被允许先生成一段用户通常看不到的思考，再作答

⚡ 普通模型

问题 ──▶ 答案

快、便宜、日常问题够用；遇到多步推导容易一步错步步错

📝 推理模型

问题 ──▶ 思考…（隐藏） ──▶ 答案

数学、代码、复杂规划显著更强，代价是更慢、更贵、输出更长

2024-09 OpenAI 发布 o1，把「思考链」做成了产品　·　2025-01 DeepSeek-R1 开源引爆全行业
此后 Qwen、GLM、Claude、Gemini 全线进入「会思考」时代
💡 它不是换了个更大的模型 —— 是学会了把推理过程显式写出来，再据此作答
STEP 2草稿纸内部

草稿纸上发生了什么

没有神来之笔 —— 思考链里是一次次「试一条路 → 发现矛盾 → 回退 → 换法 → 验算」，和封面那棵搜索树是同一件事

thinking（默认不展示给用户，但会计费）
> 题目要求 x 的范围，先按通常做法设 t = √x … > 代入后得到 t²+t−6=0，解得 t=2 或 t=−3 … > 等等，t 是算术平方根，不可能为负，−3 要舍去 > 换个方法验证：t=2 → x=4，代回原式成立 ✓ > 结论：x = 4，负根舍去，准备作答
答案：x = 4（舍去 t = −3，因为算术平方根非负）
这段草稿本身就是 12 期采样机制逐 token 生成的 —— 只是它现在拿思考 token 当推理空间
💡 回退与自我纠错不稀奇，稀奇的是：这些动作是训练后自发长出来的，没人逐条教
STEP 3test-time compute

第二条变强的轴：多想一想

过去变强只靠训练时堆规模；推理模型打开了第二条轴 —— 在回答时投入更多计算

🏋️ 训练时投入

更多数据、更大参数 —— 一次投入，所有回答共享

🧠 推理时投入

每个难题单独多想一会儿 —— 按题计费，随时可调

这就是「思考预算」：思考不是免费的内心戏，是真金白银的输出 token —— 难题值得，简单题浪费
💡 新的权衡观：同一道题，可以花一分钱快答，也可以花一块钱深思

STEP 6什么时候该思考

Agent 时代：思考与动手交替

工程共识已经成型 —— 思考能力内置后，架构师的工作变成配置「何时想、想多久、在哪一步停下来想」

✓ 开思考

数学证明、代码调试、多约束规划、长链路决策 —— 错一步代价大的题

✕ 关思考

闲聊、格式转换、分类打标签、彼此无依赖的并行小调用 —— 只增成本不增成功率

～ 交替思考

长工具链：拿到结果先停下来核对，再决定下一步 —— 草稿与动作穿插

think 规划→ tool 调用→ think 核对结果→ tool 再调用→ answer
prompt 也要改：推理模型不需要你写「一步步思考」—— 给清晰目标、硬约束和输出格式就好。
交替思考已被验证有效：OSWorld 计算机操作 42.2% → 61.4%
💡 思考模型不是处处高档位 —— 把预算花在真正的岔路口，才是会用
STEP 7计费细节

打表计费的三条须知

思考 token 看不见，但账单上都在 —— 用之前先立好预算

建议预留 ~25,000 token（推理 + 输出）
🧾
思考 token 按输出价计费

藏在哪里看不见，账单上都在 —— R1 输出 $2.19/M，缓存命中输入 $0.14/M，只有未命中的四分之一

⚠️
不设预算可能「只扣钱、无答案」

官方建议初期给推理 + 输出预留约 25,000 token —— 上限设太低，思考费完了还没轮到答案

📉
收益是对数曲线

想 2 倍久，正确率只多一小截 —— 定个上限，够用就收

Agent 场景配模型路由：工具循环里的关键规划用高档，周边杂活用普通模型（dev-02 期）
💡 思考是付费的 —— 为难题买时间，别为寒暄买单
RECAP全景

变强的第二条轴

思考链是试错回退的可见草稿，预算按题计费，effort 档位把它做成产品旋钮

普通直答→思考链草稿→预算换正确率→effort 分档→交替思考
📝
草稿即推理空间

思考链内部是试错、发现矛盾、回退、验算 —— 训练后自发涌现，逐 token 生成，默认隐藏但会计费

📈
第二条曲线
