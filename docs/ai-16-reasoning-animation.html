STEP 1两种答法

直接交卷，还是先列草稿

普通模型把全部本事用在「第一反应」；推理模型被允许先生成一段用户通常看不到的思考，再作答

⚡ 普通模型

问题 ──▶ 答案

快、便宜、日常问题够用；遇到多步推导容易一步错步步错

📝 推理模型

问题 ──▶ 思考…（隐藏） ──▶ 答案

数学、代码、复杂规划显著更强，代价是更慢、更贵、输出更长

2024-09 OpenAI 发布 o1，「思考链」产品化　·　2025-01 DeepSeek-R1 开源引爆全行业
此后 Qwen、GLM、Claude、Gemini 全线进入「会思考」时代
💡 它不是换了个更大的模型 —— 是学会了把推理过程显式写出来，再据此作答
STEP 2思考链内部

草稿纸上发生了什么

没有神来之笔 —— 思考链里是一次次「试一条路 → 发现矛盾 → 回退 → 换法 → 验算」

thinking（默认不展示给用户）
> 题目要求 x 的范围，先按通常做法设 t = √x … > 代入后得到 t²+t−6=0，解得 t=2 或 t=−3 … > 等等，t 是算术平方根，不可能为负，−3 要舍去 > 换个方法验证：t=2 → x=4，代回原式成立 ✓ > 结论：x = 4，负根舍去，准备作答
答案：x = 4（舍去 t = −3，因为算术平方根非负）
这段草稿本身也是 12 期采样机制逐 token 生成的 —— 只是它现在拿思考 token 当推理空间
💡 回退与自我纠错不稀奇，稀奇的是：这些动作是训练后自发长出来的，没人逐条教
STEP 3test-time compute

第二条变强的轴：多想一想

过去变强靠训练时堆规模；推理模型打开了第二条轴 —— 在回答时投入更多计算

🏋️ 训练时投入

更多数据、更大参数 —— 一次投入，所有回答共享

🧠 推理时投入

每个难题单独烧 token 多想一会儿 —— 按题计费

思考 token 预算 ↑正确率 ↑ · 延迟与成本 ↑
这就是「思考预算」：思考不是免费的内心戏，是真金白银的输出 token —— 难题值得，简单题浪费
💡 新的权衡观：同一道题，可以花一分钱快答，也可以花一块钱深思
STEP 4effort 档位产品化

一个模型，变成一条光谱

2025 年起，旗舰模型不再只有一个「思考开关」，而是按思考深度分档计价

🗯️非思考闲聊改写
🌗low简单推理
🌓medium日常默认
🌕high / max硬题攻坚

到 2026 年，每家旗舰都是一组档位 —— 非思考档也回来了：简单任务不烧思考钱
💡 调的不是智商，是这道题允许它想多久 —— 档位本质是思考预算旋钮
STEP 5什么时候该思考

Agent 时代：思考与动手交替

工程共识已经成型 —— 思考能力内置后，架构师的工作变成配置「何时想、想多久、在哪一步停下来想」

✓ 开思考

数学证明、代码调试、多约束规划、长链路决策 —— 错一步代价大的题

✕ 关思考

闲聊、格式转换、彼此无依赖的并行小工具调用 —— 实测开了只增成本不增成功率

～ 交替思考

长工具链：拿一个工具结果，停下来核对规则，再决定下一步 —— 草稿与动作穿插

think 规划→ tool 调用→ think 核对结果→ tool 再调用→ answer
Agent 主循环（05 期 / Hermes 04 期）因此升级：思考链穿插在 think → act → observe 之间 —— 后续工程篇展开
💡 思考模型不是处处高档位 —— 把预算花在真正的岔路口，才是会用
RECAP全景

变强的第二条轴

思考链是试错回退的可见草稿，思考预算按题计费，effort 档位把它做成产品旋钮

普通直答→思考链草稿→预算换正确率→effort 分档→交替思考
📝
草稿即推理空间

思考链内部是试错、发现矛盾、回退、验算 —— 训练后自发涌现，逐 token 生成，默认对用户隐藏

🎚️
思考是预算不是觉悟

test-time compute 用输出 token 换正确率；非思考/low/medium/high 档位让同一模型变成一条成本光谱

🔀
在 Agent 里穿插使用

硬题开、简单关、长工具链交替思考 —— 模型内化了思考，人负责配置在哪一步想

“训练决定它能想多深，
预算决定它这一次想多久。”
