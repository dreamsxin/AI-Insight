STEP 1选型四问

动手之前，先问自己四句

知识问答能跑通，靠的不是架构聪明 —— 是「一本书就在手边」。这四问适用于任何选题

数据 → 复用 → 评测 → 风险
Q1
数据拿得到吗？

公开数据集、免费 API、自己手上的语料 —— 没有数据的项目，架构再漂亮也是空转

Q2
架构复用多少？

五段流水线、工具循环、权限闸门、评估集 —— 积木能搬多少，成本就省多少

Q3
评测怎么定？

有没有客观对错：SQL 能不能跑通、题目有没有标准答案 —— 能自动判卷的项目才迭代得动

Q4
翻车代价多大？

只读不碰真实世界（查资料）随便试；会发消息、动浏览器、花钱的 —— 先建闸门再上线（Hermes 09 期）

四问里 Q1 权重最高 —— 数据决定项目能不能开始
💡 知识问答赢在起点：语料就是一本书，评测就是 50 个真实问题

《经典古诗文诵读》实战 demo —— 六个脚本 + Web 问答页，TF-IDF 检索 + LLM 有据回答

智能客服 / 工单

路由分流 + 知识库检索 + 工单 API + 转人工 —— OpenAI、Anthropic、LangChain 官方示例集的固定嘉宾

🧪
升级方向

TF-IDF 换语义向量 + rerank、加语义缓存、上 RAGAS 评测（忠实度 / 召回率）—— 现有 demo 的自然下一步

这一族的价值：语料随便换 —— 换教材是学科问答，换手册是客服，换 wiki 是企业知识库
💡 打牢这一族，后面每个项目都在复用它的五段流水线
STEP 3类型图谱 ②

分析生成族 —— 引入工具执行

从「答对」升级到「做对」：LLM 产出结构化结果，代码去执行，错了还能自修复

LLM 生成 SQL / 题目 → 执行 → 自动判卷
📝
出题 / 教育 Agent 首推

知识点抽取 → 生成题目+解析 → 评审 Agent 打分打回重写 —— 直接复用古诗文语料，评测天然客观

📊
CSV / SQL 数据问答 热度高

自然语言 → 生成 SQL → 执行 → 图表；有 BIRD 基准（12751 道真题，SOTA 82.95% vs 人类 92.96%）可对标

📜
合同 / 文档审查

分条款抽取 → 并行审查投票 → 风险清单；公开数据集 CUAD 可用 —— 「并行 + 投票」的教科书场景

这一族的命门：结构化输出 + 评估集 —— SQL 跑不跑得通、题目对不对答案，机器自己能判卷
💡 出题 Agent 是最顺的下一步：语料、引用、评估全部复用
STEP 4类型图谱 ③

操作执行族 —— 碰真实世界

感知-行动循环：看一眼 → 决定点哪 → 执行 → 再看一眼 —— 张力最大，风险也最大

observe → decide → act → observe…
🌐
浏览器操作 Agent 118k★

browser-use 开源爆火（118k star）；基准 WebArena / OSWorld（人类 72% vs 早期模型 12%）—— 差距就是空间

💻
编码助手 叙事成熟

读 issue → 改文件 → 跑测试 → 失败回读报错再改；SWE-bench 2294 道真题，OpenHands 91k star —— 「测试当裁判」的循环最出彩

📧
邮件 / 日程助理

分类 → 起草 → 写入日历前人工确认 —— human-in-the-loop 卡点的标准示范

这一族的命门：权限闸门 + 沙箱 —— 会点真按钮、发真邮件的项目，先看 Hermes 09 期再动手
💡 操作族翻车最贵 —— 先在沙箱里练，再碰真实世界
