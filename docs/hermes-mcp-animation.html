STEP 2自动注入

自动注入

CodeGraph 在 initialize 响应中附带 instructions 字段 —— 一段现成的「使用指南」

self.mcp_instructions = init_response.get("instructions", "")

📦 instructions

✨ Server 自动注入的「使用指南」—— Hermes 代码里没有写死一个字
💡 instructions 不是 Hermes 硬编码的，而是 MCP Server 在握手时「自我介绍」带来的

STEP 4行为对齐

行为对齐

LLM 读到强指引后，工具选择发生「条件反射」般的改变

response = deepseek_api_request(messages, tools=mcp_tools_schema)
💬 帮我分析一下 auth 模块里处理用户登录的函数在哪里？
🧠
LLM · 已读取 system 约束
✕
SHELLgrep -r "def login" ./auth/
被引导约束抑制 · 严禁 grep
✓

即使模型本来想用 grep，注入的强指引也会让它自动改道 CodeGraph
💡 这就是「行为对齐」：约束写在 instructions 里，行为改变发生在 LLM 侧
STEP 5执行与返回

执行与返回

Agent 主循环执行工具调用，图谱结果回传 messages，直到给出最终回答

while loop < MAX_LOOPS(8): execute_tool_call(...)
