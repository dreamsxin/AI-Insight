STEP 2切块

切块

整本文档没法直接查 —— 先切成带元数据的小块，等待被检索

50 页手册 → chunks（按语义段落切，不按字数硬切）
📄产品手册.pdf · 50 页 · 42,000 tokens
#12安装步骤：下载安装包 → 运行 setup → 选择目录…第 3 章
#13环境要求：Node 18+ / Python 3.10+…第 3 章
#48常见问题：安装失败请检查环境变量…第 5 章
#61版本历史：v2.1 修复登录超时问题…附录
块太大 → 检索不准；块太小 → 缺上下文 —— 粒度是第一道调参题
💡 切块决定检索精度 —— 按语义段落切，别按字数硬切
STEP 3向量化

向量化

每个 chunk 和用户问题都变成一串数字（向量）—— 意思近，距离就近

embed(text) → [0.83, -0.12, 0.45, …] × 1536 维
🔎 用户问题「怎么安装这个软件？」[0.41,…]
📄 #12 安装步骤语义：安装/部署/环境相似 0.91
📄 #61 版本历史语义：版本/修复/日志相似 0.31
「怎么安装」和「部署步骤」意思接近 —— 在向量空间里就是邻居
💡 Embedding 把「意思」变成「坐标」—— 意思近，距离就近
STEP 4检索 Top-K

检索 Top-K

问题向量飞进库里比对，按相似度排序 —— 只有最相关的 K 条入围

search(query, top_k=2) → [#12, #48]

STEP 5注入与回答

注入与回答

检索片段塞进 prompt，模型照着资料作答 —— 回答还带出处

prompt = system(仅依据资料) + [chunks] + question
发给 LLM 的 prompt
system：请仅依据以下资料回答，资料没有的就说不知道。
资料[1]（#12）：安装步骤：下载安装包 → 运行 setup…
资料[2]（#48）：常见问题：安装失败请检查环境变量…
user：这个软件怎么安装？
✓ 三步安装：下载安装包、运行 setup、选择目录；若失败先检查环境变量。　[1][2]
回答带出处 —— 可核对、可追溯，幻觉也少了一大截（呼应 03 期）
