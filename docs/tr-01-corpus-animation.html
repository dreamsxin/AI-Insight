标注的三步是真正拉开差距的地方 —— 同样的网页，去重和质量分不同，训出来的模型不是一个水平

后面每一步都在做同一件事：从十倍的数据里，挑出值得学的那一份
02 · 去重

同一句话，听了三十遍

网页之间大量互相转载。重复数据不会让模型更懂，只会让它背下来 —— 这正是幻觉的一个来源。

文档 A
文档 B
实色 完全相同的片段浅色 改了几个字
精确去重
比指纹

整篇算一个 hash，相同直接丢。快，但只能抓住一字不改的转载。

近似去重
比片段集合

把文章切成若干片段，采样算 Jaccard 相似度。超过阈值就判为重复。

近似去重的门槛通常是 Jaccard > 0.8 —— 保住改写，去掉转载
03 · 质量

什么叫「好文本」

机器不认识好坏，所以先给它一套可以计算的判据。

📏
长度与结构

太短的多是导航条和评论，太长的多是拼接页。段落数、句长分布都算信号。

🔣
符号比例

乱码、菜单、代码片段混在正文里，符号占比会异常。这一步几乎零成本。

🎓
训个分类器打分

拿维基、教材、获奖书籍当正例，训一个小模型给网页打「像不像教科书」的分，按分位截断。

前两条是规则，第三条是学习 —— 用干净语料当尺子，去量脏语料

这一步的产出不是「留下好数据」，而是给每篇文档一个分数，让配比阶段有得挑
04 · 配比

喂什么，长什么

总量定了之后，比例决定能力分布。这是训练里最像「配方」的一步。

代码28%逻辑与结构
网页26%世界知识
数学18%推理链
中文16%母语
书籍论文12%长文连贯

示意比例，各家的真实配比都是核心机密 · 代码给结构，网页给常识，数学给推理链

配比错了不是「少学一点」，是偏科 —— 代码放多了模型说话像 README
05 · 预算

二十倍，还是两百倍

同样的算力，可以训一个大而短的模型，也可以训一个小而久的模型。
后者更划算 —— 因为推理是永久的。

20×
算力最优
Chinchilla
285×
部署最优
今天的做法

（柱高为示意，非等比）每个参数配 20 个 token 是「把这一轮训练做到最省」；
配到两百倍以上，是把未来几年的推理账单做小

训练花一次钱，推理花一辈子钱 —— 所以模型宁愿「过度训练」
尾声

数据是世界的压缩包

文本 → 压缩 → 参数 14.8T token 671B 个数 压缩得好 = 抓住了规律 = 能泛化 压缩得差 = 只记住了原文 = 会背不会用

模型没有一张存着原文的表。
它把这些文本压进了参数里 —— 压得越狠，越像懂了。
