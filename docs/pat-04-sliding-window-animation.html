STEP 2最省事，也最危险

裸截断：从头删

实现只要一行 —— 可最早的消息里，住着最基础的事实

✂️ slice(-N)
system你是出行助手……删？
user我是杭州人 ← 关键事实删！
user明天天气？
tool{ weather: … }
user周末去哪徒步？保留

用户：我不是说过了吗？😤
💡 截断删的不是旧消息 —— 是模型世界观的地基
STEP 3一扇滑动的窗

钉住头顶，保住尾巴

system 永不滑出，只留最近 N 轮 —— 窗口向右滑，旧的出窗、新的滑入

◀ 出窗user · 我是杭州人灰化保留 0 轮
◀ 出窗tool · { weather: … }灰化保留 0 轮
🪟 WINDOW · N = 4system 钉死 📌
system 📌你是出行助手……永不滑出
user周末徒步路线？窗内
assistant推荐九溪烟树……窗内
user那附近有素斋吗？＋新滑入
💡 出窗的事实仍会忘 —— 长期事实交给记忆库（pat-03）
STEP 4滑出之前，先榨干

摘要压缩：滚成一张便签

出窗消息不直接扔 —— 一次模型调用压成摘要，带便签继续走（ai-07 / hermes-02）

📜 出窗原文 · 第 1–12 轮
📝 摘要便签

5.8k token 原文 ⟶ 1.6k token 摘要
🔑 数字/决定必须留 🔁 摘要可递归滚动
💡 窗口保眼前，摘要留住过去的骨架
STEP 5三招不是三选一

生产环境：夹成三明治

每轮输入分层拼出，再按预算裁剪（hermes-13 五层组装）

📌 system · 人设 / 规矩 / 工具永不裁剪
