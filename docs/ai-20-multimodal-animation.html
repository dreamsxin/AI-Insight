STEP 2从接骨到原生

不是外接插件，是一起长大

早期多模态是「视觉模块 + 纯文字大模型」拼接；2025 年后的旗舰从训练第一步起就混合图文音视频数据

🧩 早期拼接（LLaVA 式）

视觉编码器（冻结） 投影层（小修） 纯文字 LLM

像给语言模型装义眼：能看图，但图文理解是「翻译」过来的

🌐 原生多模态

文本 / 图像 / 音频 / 视频 同一套 token 与骨干 从预训练起混合

Gemini 3 等旗舰在模型卡里直接写明：原生支持，非旧模型微调

📄 工程前沿：文档类图像可被压成更「文本化」的高密度视觉 token（DeepSeek-OCR 路线）—— 同样一张图，用更少 token 承载更多信息
音频同理：声波切成帧、编码成向量 —— 模态千变万化，进门之后都是向量序列
💡 多模态的终点不是「什么都能输入」，而是不同感官在同一套表示里互相打通

🎨 生成时：文字引导着去噪从纯噪声出发，在 prompt 约束下反复擦噪 —— 所有位置同时修正，不是逐字排队
💡 自回归是排队写字，扩散是全员一起反复改错 —— 两条生成范式的根本分野
STEP 4从图片到视频

给方格加上时间维

视频生成把扩散从「平面方格」推广到「时空方块」：相邻帧的方块一起去噪，画面因此连贯

把每帧切成空间 patch，再沿时间叠成 时空 patch 序列，交给扩散 Transformer（DiT）统一去噪 —— 模型同时考虑「这一帧长什么样」和「上一帧发生了什么」
2024 年 Sora 把这套「世界是 patch 序列」的叙事带入大众；2025–2026 的视频模型已可同步生成原生音频、秒级到十几秒 1080p，并能对局部做修改
💡 视频不是「很多张图」，而是时空一起去噪的一个整体 —— 连贯感来自联合生成
