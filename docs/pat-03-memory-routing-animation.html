STEP 5用时怎么取

一个问题，三路各取所需

Router 先判类型，分流去取，再汇合注入

🎤「周末想带爸妈吃顿清淡的，有推荐吗？」
🧭 ROUTER：偏好 + 城市 + 上次教训 + 用餐规矩
📘 semantic口味清淡 · 带老人 · 城市=杭州
📒 episodic上次某店排队 1 小时，体验差
📗 procedural规矩：推荐前先确认城市与人数
📥 去重 + 预算裁剪 → 拼成 <relevant-memories> 注入本轮（hermes-13）
💡 记忆的价值不在库存大 —— 在该想起时恰好捞到那几条
